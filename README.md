# PROJECT K

《PROJECT K》是一款 16×16 像素风斜俯视动作 Roguelite。玩家在每局随机生成的翡翠林地中对抗兽潮、收集卡牌和武器，并携带本局成长进入三阶段炎魔战。

核心循环：`兽潮战斗 → 武器与成长选择 → 收集寒霜卡牌 → 挑战炎魔 → 获得传说奖励`。

## 运行方法

1. 使用 Godot 4.3 或更高版本导入本目录的 `project.godot`。
2. 按 F5 运行项目。
3. Renderer 使用 Compatibility，无外部插件依赖。

## 操作

- `WASD` / 方向键：八方向移动
- `J` / 鼠标左键：当前武器普通攻击；基础法杖可连续输入完成三段连招
- `Q` / 鼠标右键：消耗法力发射元气弹
- `K` / `Shift`：翻滚，带短暂无敌
- `1` / `2` / `3`：基础法杖 / 当前限时潮汐法杖 / 当前限时疾风弓
- `E` / `Enter`：在东北祭坛进入炎魔战

## 游戏流程

1. 选择青袍法师进入林地；地形、河道、三座桥和遗迹墙会随每局重新生成。
2. 清理兽潮至 2 只残敌可推进波次；第 2 波完成后从三项成长中选择一项。
3. 怪物可能掉落潮汐法杖或疾风弓；拾取后自动装备并持续 10 秒，重复拾取会刷新时长。
4. 普通怪以 40% 独立概率掉落卡牌；第 3 波后可进入东北祭坛。
5. 炎魔共有三个阶段，会逐步增加连斩、冲锋、火球与雷暴的组合压力。
6. 炎魔到达 2/3 和 1/3 生命时暂停战斗，玩家可施放本局收集的卡牌削弱下一阶段。

## 主要系统

- 八方向移动、命中帧、三段连招、翻滚无敌、命中停顿、受击闪烁、镜头震动与像素音效
- 三种固定定位武器：基础法杖、消耗法力的潮汐法杖、快速无消耗的疾风弓
- 普通、疾行、重装与远程怪物，具备巡逻、警戒、脱战和墙体绕行行为
- Seed 驱动的随机林地：河流、三座可通行桥梁、全实体遗迹墙和无碰撞花草
- 无限兽潮、场上数量上限、成长选择、武器掉落和重复装备续航转化
- 玩家、怪物与炎魔的世界空间生命/能量显示，以及林地和炎魔战独立 HUD
- 缩圈炎魔场地、三阶段攻击组合、两次卡牌施放窗口与胜败结算
- 对炎魔累计造成 40 点攻击伤害会掉落一次补给，包含 10 秒限时武器与回血药剂
- BGM 循环、本地存档和自动化冒烟测试

## 素材与授权

人物采用 Shade 的 `Free 16x16 Puny Character Sprites`（CC0）；音乐采用 Deviruchi 音乐包。野外、花草、装备图标、攻击弧光与命中音效的来源记录保存在对应素材目录的授权文件中。

炎魔火球与雷暴动画来自 OpenGameArt：DevWizard 的 `Pixel Art Spells` 与 StarsteelGaming 的 `Spell Effects`，均为 CC0，授权记录位于 `assets/cc0_boss_fx`。

玩家连招月牙与炎魔重击素材分别来自 Emcee Flesher 的 `16x16 Simple Fantasy RPG FX` 和 Raja_Kutai 的 `Slash`，均为 CC0，授权记录位于 `assets/cc0_combo_fx/LICENSE.md`。
